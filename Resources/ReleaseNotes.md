Download the **arm64.dmg** asset for Apple Silicon Macs running macOS 14 or later.

Quit AIUsage, open the DMG, and drag **AIUsage** onto **Applications**. Choose **Replace** when updating. Eject the image and open AIUsage from Applications; it lives in the menu bar. The information button shows the installed version and app location.

This build is ad-hoc signed and is not Apple-notarized. If macOS blocks the downloaded app, use **System Settings → Privacy & Security → Open Anyway** after trying to open it.

The accompanying `.sha256` file verifies the installer download. Each successful update to `main` publishes a new version here; updating the installed app is manual.
